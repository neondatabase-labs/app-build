## Development

1. Setup the .env.local file according to the .env.local.example file
```bash
VERCEL_TOKEN=
```

2. Setup the template .env file according to the .env.example file
```bash
CLOUDFLARE_API_TOKEN=
CLOUDFLARE_ACCOUNT_ID=
```

3. Install dependencies
```bash
bun install
```

4. Run the development server
```bash
bun dev
```
